## Pattern

**{{PATTERN}}**

- `full-pipeline` — staging gates production. GitHub Actions deploys
  to staging on push to `develop`; production on tag push.
- `prod-direct-with-git` — single environment (production). Push to
  `main` triggers production deploy (gated by backup ack).
- `prod-direct-no-ci` — no CI/CD. `rsync` from local on demand (gated
  by backup ack).

## Permissions matrix

| Action | Claude can do autonomously? | Requires human go-ahead? |
|---|---|---|
| Push to feature branch | yes | — |
| Merge feature into `develop` | (review-then-merge) | yes if team-mode |
| Deploy to staging (auto via GHA on push) | yes | — |
| Tag a release | no | yes |
| Production deploy | no | yes (backup ack) |
| Direct edit on production via SSH | no | yes (backup ack + warn) |
| `wp search-replace` on production | no | yes (backup ack) |
| `wp db import` on production | no | yes (backup ack) |

## Deploy commands

### Push to staging

```bash
git checkout develop
git pull
git merge feat/{your-branch}
git push origin develop
# GHA fires: .github/workflows/staging.yml deploys to staging
```

Or for the manual path (no CI):

```bash
bash ~/.claude/skills/norml-wp-developer/scripts/deploy-to-staging.sh {{SLUG}}
```

### Promote to production

```bash
git checkout develop
git tag v1.2.3 -m "Release v1.2.3 — {short summary}"
git push origin v1.2.3
# GHA fires: .github/workflows/production.yml deploys to production
# Workflow dispatch input "i_have_a_backup" must equal "yes" or the
# deploy step is skipped.
```

Or for the manual path:

```bash
bash ~/.claude/skills/norml-wp-developer/scripts/deploy-to-prod.sh {{SLUG}}
```

### Rollback

- Re-deploy the previous Git tag: check out the tag, build, run the
  deploy workflow against it.
- OR restore from the backup (host panel for `host-automatic`,
  manual for `manual-before-deploy`).

## Pre-deploy hooks

- `npm run build` (if `package.json` exists)
- `composer install --no-dev --optimize-autoloader` (if `composer.json`
  exists)
- (Sage projects) `vendor/bin/pint --test` for lint check
- (Sage projects) `vendor/bin/phpstan` for static analysis if
  configured

## Post-deploy hooks

- `ssh {{PROD_SSH_ALIAS}} "cd {{PROD_WP_PATH}} && wp cache flush"`
- (Sage projects) `wp acorn view:cache`
- Smoke test: `curl -sf {{PROD_URL}}/` returns 200
